# Menu de Jogo em GML2

Este projeto consiste em um menu interativo desenvolvido em GML2 para um jogo, incorporando funcionalidades voltadas para a experiência do usuário e persistência de configurações.

## Funcionalidades Implementadas

- 🎵 **Música de fundo (BGM)** para imersão no jogo.

- 🔊 **Controle de volume** ajustável pelo usuário.

- 🖥️ **Configuração de resolução** personalizável conforme a preferência do jogador.

- 💾 **Persistência de configurações**, garantindo que as preferências do usuário (volume e resolução) sejam mantidas após o encerramento do programa.

- 📁 **Armazenamento em arquivo**, registrando configurações para carregamento automático na próxima execução.

## Melhorias em Desenvolvimento

- Refatoração das **variáveis globais** para aprimorar a passagem de parâmetros e modularidade do código.

- Otimização do fluxo de navegação no menu para melhor usabilidade e eficiência.

## Como Utilizar

1. Compile e execute o código no GameMaker Studio 2.

2. Ajuste as configurações desejadas dentro do menu.

3. Feche e reabra o jogo – as configurações personalizadas serão carregadas automaticamente.

## Requisitos Técnicos

- **GameMaker Studio 2** para desenvolvimento e execução.

- **Suporte a manipulação de arquivos**, permitindo a persistência das configurações.

Este projeto está em evolução e aberto a contribuições para refinamento e expansão das funcionalidades.
